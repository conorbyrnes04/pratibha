# Voice recording plan

Return here when the microphone is out. Record Conor, not a stock voice.
English only: **translation, then commentary, then the practice**.
Skip Original / IAST until pronunciation is something you would stand behind in a room.

The twelve Session 1 practices were rewritten in the Agni Agama voice
(moon / sun / fire, kleśas): sensory, ordinary life, one executable sit.
Read them from the unit before you record. Same sit every time, about five
minutes. If a student would flinch and say “that isn’t Conor,” do not ship
a clone of it.
