# Pratibhā — iOS 26 app

A native SwiftUI reader for the Pratibhā corpus. **Phase 1: The Reader** —
Today, Library, the seven-layer Passage view, guided Paths, and an in-context
Journal. Everything reads **fully offline**; the corpus is bundled on device.
(Ask / RAG chat is the Phase 2 conversation layer — it will talk to the
existing FastAPI backend.)

Built against **iOS 26** (Liquid Glass). Requires **Xcode 26+**.

## Run it

The `.xcodeproj` is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen),
so it is not committed. Generate and open:

```bash
brew install xcodegen        # once
cd ios
xcodegen generate
open Pratibha.xcodeproj
```

Then pick an iPhone simulator and hit Run (⌘R).

Or build + launch from the command line:

```bash
cd ios
xcodegen generate
xcodebuild -project Pratibha.xcodeproj -scheme Pratibha \
  -sdk iphonesimulator -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build
xcrun simctl install booted "$(find build -name Pratibha.app | head -1)"
xcrun simctl launch booted com.semantikmatch.pratibha
```

> Before shipping to TestFlight, set `DEVELOPMENT_TEAM` in `project.yml` to your
> **paid** Apple team ID and reserve the bundle id on that team first.

## Regenerating the bundled data

The app ships two JSON files, generated from the repo's canonical corpus:

```bash
# from the repo root
uv run python ios/scripts/build_corpus_json.py   # -> Pratibha/Resources/corpus.json  (612 passages)
node ios/scripts/build_paths_json.mjs            # -> Pratibha/Resources/paths.json    (4 guided paths)
```

`build_paths_json.mjs` keeps only paths whose passage anchors exist in the
corpus (8 tracks that reference not-yet-imported collections — Yoginīhṛdaya,
Plotinus, Bhagavad Gītā, Phaedo-MD — are dropped automatically).

## Architecture

The durable split from the proposal: **reading is on-device, only the
conversation needs a server.**

| Layer | Where |
|---|---|
| 612 passages + 4 paths | Bundled JSON, loaded once by `CorpusStore` |
| Journal + progress | On device via SwiftData (`JournalEntry`) |
| Library / Today / Passage / Paths | 100% offline |
| Ask (RAG chat) | Phase 2 — the existing FastAPI + pgvector backend |

### Layout

```
Pratibha/
  App/            PratibhaApp (entry, SwiftData container) · RootView (4-tab shell)
  Models/         Passage · Corpus · LearningPath · JournalEntry
  Data/           CorpusStore (@Observable, loads bundle, search/daily/random)
  DesignSystem/   Theme (pigment palette) · Typography · GlassCard · YantraView …
  Features/
    Today/        Arrival screen — daily passage, continue-path, last reflection
    Library/      Collections · themes · search · CollectionDetail
    Passage/      The seven-layer reader (the jewel)
    Paths/        Paths · PathDetail · GateView
    Journal/      ReflectionEditor (in-context, SwiftData)
    Ask/          Phase 2 value-prop surface
  Resources/      corpus.json · paths.json
  scripts/        build_corpus_json.py · build_paths_json.mjs
```

### Design system

- **Palette** — manuscript pigments: ink, gold leaf (the only *active* accent),
  vermillion (practice), lapis (second voice), parchment. See `Theme.swift`.
- **Type** — system serif (≈ New York) for source text + titles; SF Pro for UI.
- **Glass** — system Liquid Glass for the tab/nav bars (free on iOS 26);
  `.ultraThinMaterial` reading cards; a Canvas **breathing yantra** that pauses
  under Reduce Motion.

### Testing hook

Two launch env vars drive automated screenshots (harmless in normal use):
`PRATIBHA_TAB` (`today|library|paths|ask`) and `PRATIBHA_OPEN_DAILY=1`.
